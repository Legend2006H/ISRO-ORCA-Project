# Antigravity Global Rules for ORCA

As an AI agent working on this project, you MUST adhere to the following rules at all times:

## 1. Project Context & Handoff
- **MANDATORY FIRST STEP:** Before making any code changes or writing implementation plans, you MUST read the `development_status.md` file to understand the project architecture and what has already been built.
- Do NOT waste tokens trying to rediscover the system architecture. Trust the `development_status.md` file.

## 2. Maintaining the Handoff Document
- **MANDATORY FINAL STEP:** If you complete a task that alters the project architecture, adds a new core feature, or changes a known issue, you MUST update the `development_status.md` file to reflect these changes before concluding your session.
- This ensures that the next AI agent or developer jumping into the project has the most up-to-date context.

## 3. General Development Guidelines
- Always prioritize modular code.
- Ensure any new UI features follow the existing "cyber-ocean" styling in `styles.css`.
- Ensure mobile responsiveness for any new frontend elements.
